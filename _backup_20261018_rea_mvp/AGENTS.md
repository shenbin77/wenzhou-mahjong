项目总入口见 HANDOVER.md。当前主线为温州茶（传统麻将）；温州熟（红中放炮麻将）暂停。代码、截图与采集记录保留在各自目录，勿混用玩法或把旧副本当作当前主线。

## 命令

本根目录没有统一的安装、启动、lint 或构建配置。实际 Python 测试位于温州茶（传统麻将）/代打BOT/majiang-bot/brain_v0/tests 与 pc_bot/tests；子仓库 AGENTS.md 记录的历史工作目录和红中主线需结合总交接与当前文件核对。

```powershell
Set-Location -LiteralPath 'D:\温州麻将\温州茶（传统麻将）\代打BOT\majiang-bot'
python -m pytest brain_v0/tests pc_bot/tests -q -p no:cacheprovider
```

该命令来自子仓库既有规则及实际测试目录；是否通过以当次输出为准。

## 目录与边界

- 温州茶（传统麻将）/bot/ 是新增整合目录；代打BOT/majiang-bot/ 是 Git 子仓库。先确认依赖和入口，再运行；目录存在不等于整合完成。
- 截图、既有采集数据和日志不覆盖、不删除；修改源码前备份并记录基线。
- 保持 dry_run；ADB、模拟器操作、实战、充值或消耗房卡需明确授权。连接器排查不授权这些操作。
- 游戏内 Cocos 图标用 ADB 原生截图坐标做模板识别、点击前复核和点击后状态验证；禁止逐个试固定坐标。Windows 桌面截图与 `gui.ps1` 的坐标不可直接当作模拟器内部坐标。
- 比赛战绩页底部“查看回放”是回放码入口；已有战绩按“详情 → 回放选项 → 每局回放”进入，不把底部入口当作战绩行。
- 遇到其他玩家的入桌邀请弹窗，先确认“邀请您进入”文案与“取消”按钮，只点“取消”并复核；不点“确定”。
- 识牌、向听、胡牌与计分分别验证；离线用例不能证明真实游戏已可用。
- 用户已决定优先直接使用恢复的阿法算牌 v2.2.5；暂停新增自研辅助窗口/BOT功能。先在软件内核实 2 人／4 人、财神（癞子）、16/17 张手牌、识牌和自动操作能力；既有源码与采集数据保留，避免重复开发。
