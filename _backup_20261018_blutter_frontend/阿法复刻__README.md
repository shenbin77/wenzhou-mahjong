## CatPaw/GLM 与 Codex 的实际交接

CatPaw/GLM 对 exe 启动壳和 Cython `pyd` 做了 Windows REA/Ghidra 分析，找到方法表、函数地址和文档字符串，并写进根目录 REA 报告。它后来明确指出 Flutter `app.so` 的前端结构、融合逻辑和完整协议仍未取得；CatPaw 记录中 Linux 分析在余额不足时中止。后续在本机 D 盘 WSL Linux 完成原始 `app.so` 的 REA 导入、字符串检索和麻将侧 `.pyc` 静态提取，并把证据边界及离线对照补入同一报告。现有记录**不支持**“原版前端/后端/模型已全部复刻”的说法。

本文件夹此前放入的 `assist_tea.py`、`REA_阿法算牌_证据与MVP.md`、`GLM_分析产物说明.md`、`GLM_对照测试结果.md` 是上述维护位置的**同内容副本**，不是独立实现；文件名中的 `GLM_` 也不能作为作者归属证据。不要在这里改 `assist_tea.py` 或把它当作可单独运行的程序。原始 CatPaw 对话记录保留在 CatPaw 自己的项目目录，本文件夹不复制会话日志。
