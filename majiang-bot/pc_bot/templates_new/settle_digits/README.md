# settle_digits/ — 结算分数 OCR 字形模板

`settle_ocr.py` 需要这里的字形模板才能识别分数。
命名: minus.png / plus.png / 0.png ... 9.png（白字黑底二值图）

## 如何制作（需一张真实结算截图）

1. 在 PC 上跑: `python settle_ocr.py --train <结算截图.png>`
   会在 /tmp/glyphs/ 输出 ROI/bw/各字形切片 g0.png, g1.png...
2. 肉眼辨认每个切片是哪个字符,重命名为对应模板名,
   放到本目录。
3. 建议用 2-3 张不同结算截图的字形做平均(或多套模板),
   提高鲁棒性。

## 布局参考（1600x900 结算画面）

- 我方(沈瀚辰)分数 ROI: (640,630)-(980,790),底部中央,头像下方
- 负分:浅蓝白亮字,如 "-500";胜:金色亮字,如 "+4500"
- 字高约 80-100px,深色背景,二值化阈值 150
