## 缺失（3, 5, 8）
在现有结算截图中未出现数字 3、5、8。
补充途径：
1. 从更多结算截图提取（约31个房间缺结算帧，待补采）
2. 从游戏字体渲染合成（需确认字形一致）

## 两种 UI 样式
1. **点炮弹窗**：黑底，橙色(+) / 青色(−) 3D 立体字 — 本模板集针对此样式
2. **牌局结束**：米黄卡片，橙红(+) / 宝蓝(−) 扁平字 — 需另建模板集
