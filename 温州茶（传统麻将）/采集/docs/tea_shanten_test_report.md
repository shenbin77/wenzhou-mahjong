## 已知限制

1. **3+财神用启发式**：3张以上财神时，用 `base - k` 启发式而非精确枚举。3+财神极罕见（需同张牌出现3+次作为财神），可接受。
2. **编码转换**：调用方需先将 vision编码（白=67）转为引擎编码（白=73）。转换函数见 `tea_encoding_table.md`。
3. **未做端到端**：未用真实回放数据验证（需等牌型标注）。
4. **副露未处理**：当前只算手牌向听，副露（碰/杠）后的手牌需调用方自行剔除已副露牌。

## API

    is_win,            # 是否胡牌

    calc_ukeire,       # 有效进张及剩余数
    discard_analysis,  # 17张弃牌效率分析

)

# 示例
tiles = [1,1,1, 2,3,4, 5,6,7, 21,21,21, 22,22, 47,48,49]  # 17张
calc_shanten(tiles)  # -1（胡牌）
calc_shanten(tiles, caishen_id=5)  # 财神=5万

# 听牌
ting = calc_ting_tiles(tiles[:16])  # 16张

# 弃牌（17张摸打后）
best = best_discard_by_efficiency(tiles)  # [(score, tile), ...]
