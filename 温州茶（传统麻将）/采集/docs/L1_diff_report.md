## 4. 主要误差来源 (按影响排序)

1. **模板缺失11张** (筒7/8/9, 条4-9, 南, 白): 遇到这些牌会标unknown，
   导致牌型判断不完整。这是最直接的识别率损失。
2. **标签词汇鸿沟**: 引擎要的是 `qingyise_unordered` 这类精确标签，
   从原始牌面到标签需要一层"牌型分析器"，目前不存在。
3. **结算帧与手牌帧未关联**: 26张结算帧和576局手牌帧是孤立的，
   没有meta.json记录"这局谁胡、什么牌型"，无法自动对比。
4. **OCR数字缺失**: 3/5/8无模板，结算分数含这些数字时读错。
