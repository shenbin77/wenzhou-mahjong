## 转换函数

```python
def vision_to_engine(vid: int) -> int:
    """tile_vision ID → 茶引擎 ID"""
    return {66: 72, 67: 73}.get(vid, vid)

def engine_to_vision(eid: int) -> int:
    """茶引擎 ID → tile_vision ID"""
    return {72: 66, 73: 67}.get(eid, eid)
```

## 使用规范

1. **shanten.py**（向听计算）：使用**茶引擎编码**（白=73）
2. **pattern_analyzer.py**（牌型分析）：使用**茶引擎编码**（白=73）
3. **tile_vision.py**（视觉识别）：输出**vision编码**（白=67）
4. **边界转换**：在 bot 主循环中，vision 识别结果 → 立即转换为引擎编码 → 再传入 shanten/analyzer

## 牌墙

- 默认（无中发）：32种 × 4张 = 128张
- 含中发：34种 × 4张 = 136张
- 财神：由翻牌决定，为某张具体的牌ID（非固定）
